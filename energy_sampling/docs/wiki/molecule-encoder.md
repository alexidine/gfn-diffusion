# Molecule encoder

*Drift: **M** (mixed). Verified against commit `a637e70`, 2026-09-20. Sources at the end.*

The molecule encoder reads a molecule as a 2D labelled graph and returns a per-atom embedding $h_i$ and a pooled vector $g$, which together are the condition a conformer policy is given. It is `models/graph_encoder.py::MPNNEncoder`, trained by the self-supervised probe battery in `models/encoder_probe.py` and consumed frozen through a stamped cache in `models/encoder_cache.py`. It sees no geometry. Left out and named: attaching an embedding to a conformer batch and padding it into a mixed-molecule carrier is [conformer-conditioning-and-carrier](conformer-conditioning-and-carrier.md); the condition library is [molecule-conditions-and-anchors](molecule-conditions-and-anchors.md); the torsion tree and its `spec` are [conformer-chart-and-internal-coordinates](conformer-chart-and-internal-coordinates.md).

## Inputs, and what each is a function of

`models/encoder_probe.py::atom_features` builds `[n, 15]`: a one-hot over `ELEMENTS` (seven values), a one-hot degree saturating at `MAX_DEGREE`, one parity column, one `is_root` column marking a single atom, which `::build_sample` takes from `models/graph_encodings.py::canonical_root`. `::graph_from_smiles` supplies elements and a bond list with explicit hydrogens, and parity as `::cip_codes` reduced to $\{-1,0,+1\}$; `::bond_features_from_smiles` gives a four-column one-hot bond order (single, aromatic, double, triple), duplicated over both edge directions at sample build; `::shortest_paths` gives integer BFS distances with unreachable pairs marked `UNREACHABLE` ($-1$). Parity is the only chirality signal: every other quantity is a function of the adjacency, and two enantiomers share an adjacency.

Two structural encodings exist. `::rwse` returns $\mathrm{RWSE}(i)[s] = \big((AD^{-1})^{s+1}\big)_{ii}$, a matrix power and so a function of the graph alone. `::lap_pe` returns rows of the lowest non-trivial eigenvectors of the normalised Laplacian from `numpy.linalg.eigh`; each eigenvector is fixed only up to sign and, inside an eigenspace of multiplicity $m$, only up to a rotation in $O(m)$, so its output is not a function of the graph, which `tests/models/test_graph_encodings.py::test_lap_pe_is_not_a_function_of_the_graph` asserts by relabelling benzene. `::ARMS` holds four arms over the encodings `none` and `rwse` only, so `lap` is reachable only through a direct `::build_sample` call. `::determinism_gate` rebuilds one molecule's encoding five times in one process at `atol=1e-10`.

## The layer

`MPNNEncoder` runs `layers` identical blocks, each a local step then a global step, both residual with a `LayerNorm`. The local step forms a message from `[h_src, h_dst, edge_attr]`, scores it with `mscore`, and aggregates over each destination atom's own incoming edges as a `::scatter_softmax`-weighted sum concatenated with a plain `::scatter_sum`. The max subtraction in `::scatter_softmax` is per graph, so weights do not depend on batch composition (`tests/models/test_graph_encoder.py::test_embedding_does_not_depend_on_batch_composition`).

The global step is one of two. With `attention=True` it is `::SPDAttention`: scaled dot-product logits plus `spd_bias(bucket(spd))`, where `::SPDAttention.bucket` clamps distances into `0..max_spd` and sends negatives to bucket `max_spd + 1`; padded keys are masked to $-\infty$, a fully padded row is `nan_to_num`'d to zero, and the output is `(proj(routed) + proj_sum(summed))` times the padding mask, with `summed` the mask-weighted sum of values broadcast to every position. `spd_bias` and `proj_sum` are zero-initialised, so the block begins as unbiased attention with no extensive channel. With `attention=False` the global step is a rank-one aggregate and broadcast from `bscore`, `bcast` and a zero-initialised `bcast_sum`. Passing `spd` to a non-attention encoder raises rather than being ignored, and a `spd` not shaped `[G, L, L]` raises naming `::dense_spd_batch`, which fills padding with $-1$ so a padded key reads as unreachable rather than as an atom at distance zero. The readout is `h` per atom and `g`, the softmax-weighted sum concatenated with the plain sum, of width `2 * hidden`.

## The targets and how they are scored

`::PROBES` holds nine `Probe` records: `formula`, `degree_hist`, `pi_degree`, `smallest_ring`, `eccentricity`, `spd_to_marked`, `orbit_size`, `cip_code`, `chiral_moment`. Every label is computed from the graph by a function in `models/graph_encodings.py`, so no label noise enters. Each probe gets one `nn.Linear` head over the shared `h`; `::target_stats` standardises the targets, `::ProbeModel.loss` sums per-probe MSE, and `::score` un-standardises and counts a hit on an `integral` probe when every component rounds to the label, and on a non-integral probe when every component is within 1% relative. `Probe.nonzero_only` restricts both loss and score to rows whose label is non-zero. `::RETIRED` names seven targets withdrawn on 2026-08-31.

`chiral_moment` is $\sum_i c_i w_i$ with $c_i$ the CIP code and $w_i$ a per-atom weight. An earlier construction took $w_i$ from `models/graph_encodings.py::wl_colours`, which iterates `hash((colour, sorted neighbour colours))` and returns `abs(c) % modulus + 1` at a default modulus of 97. The hash preserves class identity, so two atoms of one Weisfeiler-Lehman colour share a weight, and destroys everything else: the residue bears no relation to any property of the colour that varies with the graph. A model predicts through features it computes, so for an atom whose colour never appeared in training no computed feature constrains $w_i$; the best prediction conditional on everything visible is the marginal mean of the residue, and the per-atom squared-error floor is its variance, near $(m^2-1)/12$ for residues spread over $m$ values. That floor does not fall with training size. The shipped weight is $1 + d(i,\text{root})$ with an unreachable atom scored at $d = 0$, the same distance the `spd_to_marked` label carries; `wl_colours` is imported into `models/encoder_probe.py` and called by no probe there.

On `cip_code` the scored labels are $y \in \{-1,+1\}$. Under a squared loss the minimiser given whatever the model conditions on is the conditional mean, so a model whose sign is right with probability $p$ predicts $q = (+1)p + (-1)(1-p) = 2p-1$. `::score` rounds, and $\mathrm{round}(2p-1) = \pm1$ requires $|2p-1| > 0.5$, that is $p > 0.75$ or $p < 0.25$. In between the rounded prediction is $0$, which equals no scored label, so exact match is $0$ until $p$ passes $0.75$.

## Kendall uncertainty weighting

`::ProbeModel` carries `log_sigma`, one scalar $s$ per probe, used when `weighting == 'uncertainty'` (reachable by `--loss-weighting uncertainty`). That branch adds $\tfrac12\,\mathrm{mse}\,e^{-2s} + s$ per task. Differentiating in $s$ gives $-\mathrm{mse}\,e^{-2s} + 1 = 0$, so $s^{*} = \tfrac12\ln\mathrm{mse}$ and the effective weight on that task's MSE is $e^{-2s}/2 = 1/(2\,\mathrm{mse})$. Substituting back, the task contributes $\tfrac12\ln\mathrm{mse} + \tfrac12$ to the shared parameters, whose gradient is $\nabla\mathrm{mse}/(2\,\mathrm{mse})$: scale free in the MSE and unbounded as it falls. Since $s$ is descended rather than solved it trails the MSE, so along a trajectory on which a task is fitted its weight rises. `ProbeModel.weighting` defaults to `'none'`, equal-weight MSE on already standardised targets, where every task starts near an MSE of one; the uncertainty branch was the default until 2026-09-01.

## The split is on the structural equivalence class

`::load_qm9_stereo` assigns a chiral tag at every tetrahedral centre RDKit's `FindPotentialStereo` reports, seeded per molecule from a `blake2b` digest of its SMILES, so a molecule receives the same assignment at every dataset size. Two molecules differing only in those assignments share an adjacency, and so share every probe label except the two stereo ones.

`::parent_skeleton` strips stereochemistry and returns the canonical SMILES of the remainder. `::main` groups built samples by that key, permutes the group keys with `numpy.random.default_rng(12345)`, emits each group's members contiguously, takes the first `n_test` rows as held out, advances the boundary while `gid[n_te] == gid[n_te - 1]` so no group straddles it, and asserts `leak == 0`. `models/encoder_cache.py::build_cache` keys on the stereo-specific canonical SMILES, so diastereomers do not share an embedding. `::mirror_smiles`, which inverts every tetrahedral centre, is defined in the module and called nowhere in the repository.

## The atom-order contract

The two paths order atoms differently: `::graph_from_smiles` returns RDKit's order with hydrogens appended by `AddHs`, while the conformer path renumbers into the torsion tree's placement order. The map is `spec.perm`. `models/encoder_cache.py::embed` encodes in encoder order and, when `perm` is passed, permutes `h` once into tree order; with `z_tree` also passed it checks `z_enc[perm] == spec.z` and raises `ATOM ORDER MISMATCH` otherwise, and raises separately when `perm` and the built molecule disagree on atom count. `::lookup` re-checks the stored `z_tree` against the batch and `::load_cache` refuses a cache whose recorded `sha256` differs from the encoder checkpoint it is given. Without the permutation the shapes still agree, so every atom is conditioned on another atom's embedding and nothing raises. The parity conventions also differ: `graph_from_smiles` carries the CIP-referenced sign, `energies/dof_features.py::atom_parity` the improper-dihedral sign read off the reference conformer in placement order; they agree on which atoms are stereocentres and may disagree on sign.

## Config keys

The encoder carries no keys in the canonical config: `models/encoder_cache.py::load_encoder` reads `hidden`, `layers`, `attention`, `k` and `arm` from the checkpoint and infers `n_heads` and `max_spd` from the `[max_spd + 2, n_heads]` shape of `encoder.attn.0.spd_bias.weight`. Training is driven by `::main` flags, among them `--arms`, `--sizes`, `--n-test`, `--steps`, `--k`, `--probes`, `--loss-weighting`, and `--stereo` and `--match-params`, which default on with `--no-` counterparts. On the run side `cfg:embedding_conditioning` opens the conditioning channel and `cfg:embedding_conditioning_dim` sets its width; `build_conformer_conditions.py` prints `2 * hidden` as that width for a cache built here, while the canonical config's `192` is the crystal route's flattened Mo3ENet latent.

Code: `models/graph_encoder.py::MPNNEncoder`, `::SPDAttention`, `::dense_spd_batch`, `::scatter_softmax`; `models/graph_encodings.py::rwse`, `::lap_pe`, `::wl_colours`, `::cip_codes`, `::graph_from_smiles`, `::canonical_root`; `models/encoder_probe.py::PROBES`, `::Probe`, `::ProbeModel.loss`, `::score`, `::atom_features`, `::build_sample`, `::parent_skeleton`, `::load_qm9_stereo`, `::determinism_gate`, `::ARMS`, `::main`; `models/encoder_cache.py::load_encoder`, `::embed`, `::build_cache`, `::load_cache`, `::lookup`; `energies/dof_features.py::atom_parity`.

## Could be tooling

A target audit could report, per probe, the tolerance as a fraction of one SD that `::probe_tolerances` computes over live components, its trivial-predictor floor from `::size_only_baseline`, and whether its value is determined by features the encoder receives. A cache audit could take an embedding file and a condition library and re-assert `z_enc[perm] == spec.z` and the checkpoint fingerprint without rebuilding either.
