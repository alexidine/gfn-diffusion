# Autoregressive spline flow

*Drift: **M** (mixed). Verified against commit `56577dd7`, 2026-10-22. Sources at the end.*

`inn_modeller.py` replaces the SDE policy and $P_B$ of a crystal run with one invertible map, and this page is about that map as a density: `inn_modeller.py::LatentFlow`, a masked autoregressive flow over the live rows of the crystal latent whose per-row transform is the monotone rational-quadratic spline of `energies/prior_flow.py::_rq_spline`, with a masked-MLP or a causal-transformer conditioner. It covers the three kinds of row and their base distributions, the blocks and their row orders, the exact log-density and how a draw inverts it, the spline inside one bin, the bin-height floor, the two knot-derivative options, and which settings live in the weights. Named and left out: the exact-density trainer in the same file (its likelihood stage on stored prior rows, its energy stage on the TB residual of fresh draws and stored rows, its replay and its level); the latent rows themselves, [latent-dimension-structure](latent-dimension-structure.md); and the crystal prior flow fitted to policy draws, [prior-density-models](prior-density-models.md), which uses the same spline module with free derivatives and the default floors.

## The rows and their bases

`inn_modeller.py::InnModeller.init_gfn` builds a `models/gfn.py::GFN` from the run's config for its geometry only, reads its angular mask, its dead rows and its width, and discards it. `LatentFlow` models the live rows; a draw sets every dead row to 0, and no dead row enters a conditioner or $\log q$, so $q$ is a density over the live rows. Each live row is one of three kinds.

| kind | which rows | what the first block reads | base | spline interval | end knot derivatives | per-row shift | outside the interval |
|---|---|---|---|---|---|---|---|
| wrapped | the GFN's angular rows | the row folded onto $[-1,1]$ by `energies/prior_flow.py::_wrap` | uniform on $[-1,1]$ | $[-1,1]$ | matched, $d_K = d_0$ | rotation, $\mathrm{wrap}(x + \text{shift})$ | none, the input is folded |
| linear | every other live row | $(x-\mu)/\sigma$ | standard normal | $[-b, b]$, $b$ = `--bound` | pinned to 1 | translation, $x + \text{shift}$ | identity |
| bounded | the rows `--bounded_rows` names | the raw row ($\mu = 0$, $\sigma = 1$) | uniform on $[-1,1]$ | $[-1,1]$ | both learned | none | log-derivative $-\infty$ |

`::_Flow.set_scaler` sets $\mu$ and $\sigma$ ($\sigma$ floored at $10^{-4}$) from the training rows on the linear rows only and leaves $0$ and $1$ on the wrapped and bounded rows; `InnModeller.init_data_rows` calls it, and an `--init_from` checkpoint's saved standardisation replaces the fitted one. The standardisation is a fixed change of variable and contributes the constant $-\sum_{\text{linear}}\log\sigma_i$ to $\log q$. `energies/prior_flow.py::_Block` keeps a per-row `bound` buffer, 1.0 on wrapped and bounded rows and `--bound` on linear rows, so a linear row's spline box is $[-b, b]$ in standardised units.

On a wrapped row the spline's end knots sit at $\pm 1$ in both input and output, so the spline alone maps the seam point to itself; with $d_K = d_0$ it is a $C^1$ diffeomorphism of the circle. The shift, added before the spline and folded by `_wrap`, is a rotation with unit Jacobian, and being an output of the conditioner it depends on the rows earlier in the block's order. On a linear row the end derivatives pinned to 1 join the spline $C^1$ to identity tails, so the block is a diffeomorphism of the line. A bounded row (`--bounded_rows` takes a comma-separated list of live unwrapped latent rows, `linear` for all of them, or `none`; `inn_modeller.py::LatentFlow` raises `ValueError` on a wrapped or dead row) is a diffeomorphism of the closed interval $[-1,1]$ with no tails: `_rq_spline` returns log-derivative $-\infty$ for an input outside it, so $q = 0$ there, and `energies/prior_flow.py::rq_spline_inverse` never leaves it, a base point of a bounded row lying inside $[-1,1]$. A bounded row takes no shift, and its shift slot is read as its last knot derivative.

The conditioner does not read the row values directly: `energies/prior_flow.py::_Block._feats` gives it one column per linear or bounded row (the value) and two per wrapped row, $\sin\pi x$ and $\cos\pi x$, which are continuous across the seam.

Two further row options belong to the same object. `--fold_half_rows` names live wrapped rows whose distribution repeats every half period: `LatentFlow` models $u = 2\,((x+1) \bmod 1) - 1$ on them, and a draw maps $u$ back to $x = (u-1)/2 + i$ with $i \in \{0, 1\}$ chosen uniformly. The fold is two-to-one with $|du/dx| = 2$ and each image carries half the mass, so $q(x) = q_{\text{flow}}(u(x))$ and `LatentFlow.log_prob` carries no correction term; the option is refused with `--w_path` above 0. `--mix_k` replaces each block by `inn_modeller.py::_MixBlock`, which on each wrapped row puts the CDF map of a mixture of `--mix_k` wrapped logistics plus a uniform component of weight `inn_modeller.py::_MIX_EPS` before the spline; it requires `--block_orders` and `--conditioner transformer`, its inverse is a bisection (`inn_modeller.py::_mix_inverse`), and it is refused with `--bounded_rows`, `--tied_derivatives` and `--w_path` above 0.

## Blocks, orders and the conditioner

The flow is a stack of `--n_blocks` blocks (`energies/prior_flow.py::_Flow`), each autoregressive over all live rows in one order. With `--block_orders none` the orders cycle with the block index $n$: $n \bmod 3 = 0$ the stored row order, $1$ its reverse, $2$ a permutation drawn from a generator seeded with `cfg:seed`. `--block_orders` sets one order per block, as a comma-separated list of exactly `--n_blocks` entries (`ValueError` otherwise): each entry is `id` (live rows in stored order), `rev`, or latent row indices separated by `.`, listing every live row exactly once. Left unset (`auto`), the flag resolves as described under run settings below; on an unconditional one-block flow whose live rows are exactly 0 to 11 it becomes `inn_modeller.py::Z1_ORDER`, `8.11.10.9.7.6.5.4.3.2.1.0`.

Within a block, the conditioner reads the features of the block's input and returns $3K + 1$ numbers per row, $K$ = `--n_bins`: $K$ width logits, $K$ height logits, $K$ derivative slots and one shift slot. The numbers for the row in position $j$ of the order depend only on the rows in positions $< j$. The block then shifts each row and passes it through its spline. With $o$ the order, $v$ the block's input (the folded or standardised $x$), $y = T(v)$ its output and $p_0$ the base, a single block ($n_{\text{blocks}} = 1$) is an explicit autoregressive factorisation,

$$q(x) \;=\; \prod_{j=1}^{d} q_j\big(x_{o_j} \mid x_{o_{<j}}\big), \qquad q_j \;=\; p_0\big(y_{o_j}\big)\,\Big|\frac{\partial y_{o_j}}{\partial v_{o_j}}\Big|\,\frac{1}{\sigma_{o_j}},$$

each factor a normalised one-dimensional density for every value of the preceding rows, since given them $y_{o_j}$ is an increasing bijection of the row's domain onto the base's support and the base factorises over rows. A stack of blocks in different orders is a composition of such maps; its density is still exact, and is not in general an autoregressive factorisation in one order.

Two conditioners exist. `--conditioner made` is `energies/prior_flow.py::_MADE`: masked linear layers of widths `--hidden` repeated `--hidden_layers` times, with SiLU, the sin and cos columns of a wrapped row sharing one autoregressive degree, the output for a row masked to depend only on rows strictly earlier in the order. `--conditioner transformer` (the default) replaces each block's MADE by `energies/ar_transformer.py::CausalTransformerConditioner`: one token per slot of the order, slot $j$ carrying a linear embedding of the features of row $o_{j-1}$ plus a learned embedding of which row that is, slot 0 carrying a learned start token, every slot adding a learned per-slot embedding, which under the block's fixed order names the row the slot predicts; `--tf_layers` pre-norm layers of causal self-attention and a four-times-wide MLP at width `--tf_width` with `--tf_heads` heads; a final LayerNorm and a head shared by all slots giving $3K+1$ numbers, reordered from slot order to row order. Causal masking gives slot $j$ the tokens of slots $\le j$, which carry rows $o_{<j}$ only. On CUDA the layers run in bfloat16 and the head and spline in the input's precision; `--tf_fp32` runs the layers in the input's precision and is refused with the MADE conditioner.

Both heads start at zero weights, zero bias on the width, height and shift slots, and bias $\kappa$ = `energies/prior_flow.py::_SOFTPLUS_ONE` $= \log(e-1)$ on the derivative slots, for which $\mathrm{softplus}(\kappa) = 1$; every bin is then uniform and every shift zero. Under free derivatives a learned knot derivative is then $1 + d_{\min}$, with $d_{\min}$ = `_MIN_DERIV` $= 10^{-3}$, so each block is the identity to within a log-derivative of order $d_{\min}$; under tied derivatives the factor is exactly 1 and the bin slopes are all 1, so each block is exactly the identity.

## Density: the forward direction

The forward direction maps data to base. `energies/prior_flow.py::_Flow.log_prob`, which `LatentFlow.log_prob` calls on the live rows, folds the wrapped rows, standardises the linear rows, runs every block once and returns

$$\log q(x) \;=\; \sum_{i}\log p_{0,i}(\zeta_i) \;+\; \sum_{\text{blocks}}\sum_i \log\Big|\frac{\partial y_i}{\partial v_i}\Big| \;-\; \sum_{\text{linear } i}\log\sigma_i,$$

with $v$ and $y$ each block's input and output, $\zeta$ the last block's output (the base point), and $\log p_{0,i}(\zeta_i) = -\log 2$ on wrapped and bounded rows and $-\tfrac12 \zeta_i^2 - \tfrac12\log 2\pi$ on linear rows. The normaliser is exact by construction and evaluating it costs one conditioner pass per block.

`inn_modeller.py::InnModeller.per_dim_log_q` returns the same sum split by live row: each row's spline log-derivatives summed over blocks, its standardisation term and its base term. On unconditional runs it sums to `log_prob`, term by term from the formula above; `InnModeller.dump_draws` raises `RuntimeError` when the two differ by more than $10^{-2}$ on a draw. At $n_{\text{blocks}} = 1$ each row's term is $\log q_j$ above, the conditional log-density of that row given the rows before it in the order; in a stack a row's term sums its log-derivatives over blocks, each conditional on a different set of rows.

## Sampling: the inverse direction

`LatentFlow.sample` draws a base point (uniform on $[-1,1]$ on wrapped and bounded rows, standard normal on linear rows), inverts the blocks from last to first (a block with the causal-transformer conditioner through `inn_modeller.py::invert_block_cached`, a MADE block through `energies/prior_flow.py::invert_block`, a mixture block through `inn_modeller.py::_MixBlock.invert`), folds the wrapped rows, unstandardises the linear rows, writes the live rows into a zero vector and unfolds any half-period rows.

`invert_block` starts from $x = 0$ and applies $d$ times, $d$ the number of live rows, the update $x \leftarrow T^{-1}\big(y;\ \theta(x)\big)$: run the conditioner on the current $x$, invert every row's spline at $y$ with those parameters (`rq_spline_inverse`), and undo the shift. The parameters of row $o_1$ depend on no row, so the first pass makes $x_{o_1}$ exact. If after pass $p$ the rows $o_1, \dots, o_p$ are exact, then in pass $p+1$ the parameters of row $o_{p+1}$ are computed from exact values and $x_{o_{p+1}}$ becomes exact, while rows $o_{\le p}$ stay exact, their parameters reading only exact rows. After $d$ passes every row is exact, whatever the order, and the order is never read. On a MADE block a draw therefore costs $d$ conditioner passes against one for $\log q$.

`invert_block_cached` makes the same per-row updates in the order's sequence, one conditioner step per row. `energies/ar_transformer.py::CausalTransformerConditioner.decode` keeps every layer's keys and values for the slots already computed; step $j$ computes slot $j$'s token alone (the start token at $j = 0$, else the value embedding of row $o_{j-1}$, fixed at the step before), which attends to the cached slots and to itself, so it is the computation the full pass makes for that slot on the completed rows. The head gives row $o_j$'s parameters, the row's spline is inverted at its base value, the shift is undone, and the row's features enter the next token. The work is about one conditioner pass per block, in $d$ sequential steps, and the rows equal the $d$-pass inverse's up to rounding. On a conditional conditioner `decode` takes the context `forward` takes and raises `ValueError` when it does not match how the conditioner was built (see Conditional runs). Inside one bin `rq_spline_inverse` solves the in-bin map below for $\xi$ as the quadratic $a_2\xi^2 + a_1\xi + a_0 = 0$ with $a_2 = h(s - d_k) + Y\delta$, $a_1 = h d_k - Y\delta$, $a_0 = -sY$, $Y = y - y_k$, $\delta = d_k + d_{k+1} - 2s$, taking the root $\xi = 2a_0/(-a_1 - \sqrt{a_1^2 - 4a_2a_0})$.

`inn_modeller.py::invert_differentiable` runs the same $d$ passes with the autograd graph kept, and `LatentFlow.rsample` composes it over the blocks to give the draw `sample` makes from given base points, differentiable in the parameters. The $d$-pass map coincides with the exact inverse for every parameter value, so the derivative autograd takes through the passes is the derivative of the exact inverse.

`inn_modeller.py::InnModeller.check_sampler_round_trip` runs at start-up, after any `--init_from` load: it draws 4096 base points, samples, maps the draws back with `LatentFlow.to_base`, and raises `RuntimeError` unless the largest error on a double-precision copy of the flow is below $10^{-6}$ and the 99th percentile of the working-precision error is below $10^{-2}$ base units.

## The rational-quadratic spline in one bin

`energies/prior_flow.py::_bin_fractions` turns the width and height logits of a row into fractions $\ell + (1 - K\ell)\,\mathrm{softmax}(\cdot)$, each at least $\ell$ and summing to 1, with $\ell = \ell_0$ = `_MIN_BIN` $= 10^{-3}$ for the widths and $\ell_0$ or the row's height floor for the heights. `_rq_spline` takes their cumulative sums, normalises the last to exactly 1 and maps them onto $[-b, b]$, giving knots $(x_k, y_k)$, $k = 0, \dots, K$, bin widths $w_k$, heights $h_k$ and mean slopes $s_k = h_k / w_k$. Both coordinates are scaled by the same $2b$, so $s_k$ is the ratio of the bin's height fraction to its width fraction. With knot derivatives $d_k$ and $\xi = (x - x_k)/w_k \in [0,1]$ for $x$ in bin $k$, writing $s$ for $s_k$ and $h$ for $h_k$,

$$y \;=\; y_k + h\,\frac{s\xi^2 + d_k\,\xi(1-\xi)}{s + (d_k + d_{k+1} - 2s)\,\xi(1-\xi)} .$$

**The in-bin derivative.** Put $u = \xi(1-\xi)$, $N = s\xi^2 + d_k u$, $D = s + \delta u$ with $\delta = d_k + d_{k+1} - 2s$, primes denoting $d/d\xi$. Then $dy/dx = (h/w)(N'D - ND')/D^2 = s\,(N'D - ND')/D^2$, and expanding with $u' = 1 - 2\xi$ and the identity $2\xi u - \xi^2(1-2\xi) = \xi^2$ gives $N'D - ND' = s\,[\,2s\xi + d_k(1-2\xi) + \delta\,\xi^2\,] = s\,[\,d_{k+1}\xi^2 + 2s\,\xi(1-\xi) + d_k(1-\xi)^2\,]$, so

$$\frac{dy}{dx} \;=\; \frac{s^2\,\big[\,d_{k+1}\xi^2 + 2s\,\xi(1-\xi) + d_k(1-\xi)^2\,\big]}{\big[\,s + (d_k + d_{k+1} - 2s)\,\xi(1-\xi)\,\big]^2},$$

which is the `dnum` over `den` squared that `_rq_spline` returns as a log. At $\xi = 0$ it is $s^2 d_k / s^2 = d_k$ and at $\xi = 1$ it is $d_{k+1}$, so the map is $C^1$ across knots. Since $y$ runs from $y_k$ to $y_k + h$ across the bin, the average of $dy/dx$ over the bin is $s$. The denominator can be written $s\,[\xi^2 + (1-\xi)^2] + (d_k + d_{k+1})\,\xi(1-\xi)$; for positive knot derivatives it and the numerator are positive, and the map is strictly increasing.

**Equal knot derivatives.** With $d_k = d_{k+1} = d$ and $t = 2\xi(1-\xi) \in [0, \tfrac12]$, the derivative is $s^2\,[\,d(1-t) + st\,]/[\,s(1-t) + dt\,]^2$, whose derivative in $t$ is $-s^2(d - s)\,(m + 2n)/m^3$ with $n = d(1-t) + st > 0$ and $m = s(1-t) + dt > 0$. It is therefore monotone between its knot value $d$ at $t = 0$ and its midpoint value

$$\frac{dy}{dx}\Big|_{\xi = 1/2} \;=\; \frac{2s^2}{d + s}$$

at $t = \tfrac12$, falling when $d > s$ and rising when $d < s$; it never exceeds $\max(d,\, 2s^2/(d+s))$. Knot derivatives $d \gg s$ at both ends of a bin thus give the map a derivative $d$ at the knots, $d/s$ times the bin's average, and a derivative of order $s^2/d$ at the bin's middle. On a uniform-base row of the block whose output is the base point, the density of that block's input on the row, given the rows before it, is half the derivative, so this is a density spike at the knot and a dip inside the bin.

**Free derivatives and the bin slope.** Under free derivatives $d_k$ and $s_k$ are separate outputs of the conditioner: a knot derivative is not a function of the slopes of the two bins it joins, and the ratio of a bin's knot derivatives to its mean slope is not bounded above. Free derivatives are floored at $d_{\min}$, and $s_k$ at the height floor divided by $1 - (K-1)\ell_0$, since the other $K-1$ width fractions are each at least $\ell_0$. Under the default floors ($\ell_0 = d_{\min}$) that exceeds $d_{\min}$; a height floor below $d_{\min}(1 - (K-1)\ell_0)$ admits bins with $s_k < d_{\min}$, and in such a bin both free knot derivatives exceed $s_k$.

## The height floor

`--min_bin_height` $h_0$ sets the height floor $\ell$ of `_bin_fractions` on the rows `--min_bin_height_rows` names: `uniform` for the wrapped and bounded rows (`_Block.unit_base_rows`), `all` (the default) for every row. Rows outside the choice keep $10^{-3}$, and with `--min_bin_height none` every row keeps $\ell_0$, the floor `_rq_spline` uses when it is given no per-row floor; left unset, the flag resolves as in the section on run settings below. Widths keep `_MIN_BIN` in every case. `InnModeller.init_gfn` raises `ValueError` unless $0 < h_0 < 1/K$, with the message that at or above $1/n_{\text{bins}}$ the heights cannot move or go negative; refuses it with `--w_path` above 0, with the message "the reparameterised path gradient is unbounded inside floored bins"; and prints `bin-height floor ... on ... rows (else 1e-3)`. It sets `min_height` on every block, a per-row tensor.

What a height means depends on the row's base. Take the block whose output is the base point: the last block of the stack, or the only one at $n_{\text{blocks}} = 1$. Given the rows before it in the order, the probability that a row's value falls in bin $k$ (in the rotated coordinate on a wrapped row) is the base mass of $[y_k, y_{k+1}]$. On a uniform-base row that is $h_k/2$ on an interval of length 2, which is the bin's height fraction: the height fraction is the bin's share of the row's conditional mass. The floor is then a minimum mass per bin, the $K$ floors together fix $K h_0$ of the mass whatever the weights, and the softmax distributes the remaining $1 - K h_0$. On a Gaussian-base row the height is a length $2b \times$ fraction in base units, and its mass $\Phi(y_{k+1}) - \Phi(y_k)$ depends on where the bin sits: up to $h_k\,\phi(0)$ near the base's centre, and of order $h_k\,\phi(b)$ near the edge of the box. For an earlier block of a stack the output is the next block's input, whose distribution is neither uniform nor Gaussian, and the height fraction of a bin is not its mass.

## Knot derivatives: free and tied

**Free** (`energies/prior_flow.py::_knot_derivatives`, the default). Each derivative slot gives $d = d_{\min} + \mathrm{softplus}(\text{slot})$, unbounded above. Per row kind: a wrapped row takes its $K$ slots as $d_0, \dots, d_{K-1}$ and sets $d_K = d_0$; a linear row pins $d_0 = d_K = 1$ and takes $d_1, \dots, d_{K-1}$ from slots $0, \dots, K-2$, leaving slot $K-1$ unread; a bounded row takes $d_0, \dots, d_{K-1}$ from its slots and $d_K = d_{\min} + \mathrm{softplus}(\text{shift slot} + \kappa)$.

**Tied** (`energies/prior_flow.py::_tied_derivatives`, `--tied_derivatives`). The derivatives are functions of the bin slopes. At knot $k$, joining bins $k-1$ and $k$ (bin $K-1$ at $k = 0$),

$$d_k \;=\; \frac{2\,s_{k-1}s_k}{s_{k-1} + s_k}\; f_k, \qquad f_k \;=\; \exp\!\big(\log F \cdot \tanh(\text{slot}_k - \kappa)\big) \in [1/F,\ F],$$

with $F$ = `--tied_factor` (2 when unset and not taken from a checkpoint; `ValueError` below 1; $F = 1$ gives $f_k = 1$, the pure harmonic mean; for $F > 1$ the factor lies strictly inside the interval, $\tanh$ never reaching $\pm 1$). In `_rq_spline` the argument `tied` is the factor range, `True` meaning 2. Ends per row kind: a wrapped row uses the formula at $k = 0$, joining bin $K-1$ to bin 0 across the seam, and sets $d_K = d_0$; a linear row pins $d_0 = d_K = 1$ and leaves slot 0 unread; a bounded row sets $d_0 = s_0 f_0$ and $d_K = s_{K-1}\exp(\log F \cdot \tanh(\text{shift slot}))$. $d_{\min}$ does not enter the tied derivatives. `InnModeller.init_gfn` refuses `--tied_derivatives` with `--mix_k`, sets `tied` on every block to $F$, and prints `knot derivatives tied to the neighbouring bin slopes (harmonic mean x a factor in [1/F, F])`.

**The harmonic mean of two slopes.** For $a, b > 0$ with $m = \min(a,b)$ and $M = \max(a,b)$, $2ab/(a+b) = 2mM/(m+M)$, which is at least $2mM/2M = m$ (with equality when $m = M$) and below $2mM/M = 2m$. A tied interior derivative therefore lies in $[m/F,\ 2Fm)$ for $m$ the smaller of its two adjacent slopes: it is less than $2F$ times either adjacent slope and positive. The same holds at the seam of a wrapped row, and a bounded row's end derivatives lie within a factor $F$ of their own bin's slope.

**The in-bin bound.** Suppose both knot derivatives of a bin are positive and at most $2Fs$, $F \ge 1$. In the rewritten denominator, $\xi^2 + (1-\xi)^2 \ge \tfrac12$ and the second term is non-negative, so the denominator is at least $s/2$. The bracket in the numerator is a combination of $d_{k+1}$, $2s$ and $d_k$ with weights $\xi^2$, $2\xi(1-\xi)$, $(1-\xi)^2$ summing to 1, so it is at most $\max(d_k, d_{k+1}, 2s) \le 2Fs$, and the numerator is at most $2Fs^3$. Hence

$$\frac{dy}{dx} \;\le\; \frac{2Fs^3}{(s/2)^2} \;=\; 8F\,s$$

everywhere in the bin. Under tied derivatives the hypothesis holds in every bin of a wrapped or bounded row and in bins $1, \dots, K-2$ of a linear row; the two end bins of a linear row have one end pinned to 1, which is not related to their slope, and are excluded. In the equal-derivative case above the derivative is at most $\max(d, 2s^2/(d+s)) \le \max(2Fs, 2s) = 2Fs$, below the general bound.

The tests in `tests/models/test_rq_spline_tied.py` pin these on random parameters with $K = 32$: `tests/models/test_rq_spline_tied.py::test_pure_factor_is_the_harmonic_mean` checks $F = 1$ against the harmonic mean, `::test_knot_derivative_bound_with_negative_control` checks interior knot derivatives against $2F$ times the slope of the bin to their right at $F = 1$ and $F = 2$, and asserts that under free derivatives on the same parameters the largest such ratio exceeds 100, `::test_density_inside_bins_bounded_with_negative_control` checks $dy/dx \le 8Fs$ at $F = 2$ on bins $1, \dots, K-2$ of every row kind, and asserts that under free derivatives the largest ratio of $dy/dx$ to $s$ exceeds $10^3$, `::test_tied_inverts_and_logdet_matches_autograd` checks the inverse and the log-derivative, and `::test_tied_true_is_factor_two` checks that `tied=True` is $F = 2$.

**Identifications.** The in-bin map is the rational-quadratic interpolant of Gregory and Delbourgo (1982), monotone for any positive knot derivatives; the choice of those derivatives for it is the subject of Delbourgo and Gregory (1985). Neural Spline Flows (Durkan et al. 2019) use the same interpolant as a flow transform, with widths and heights from a softmax, interior derivatives from a softplus of an unconstrained network output, and end derivatives of 1 meeting identity tails: the free branch here, on linear rows. A circular spline with matched end derivatives composed with a rotation is the circular spline flow of Rezende et al. (2020). The tied rule's harmonic mean is the derivative of Fritsch and Butland (1984) for monotone piecewise cubic Hermite interpolation, whose general form, a formula due to Brodlie described there, weights the two reciprocal slopes by the interval lengths and reduces to the harmonic mean on equal intervals; `_tied_derivatives` uses the unweighted mean whatever the two bin widths.

## What is a run setting and what is a weight

`inn_modeller.py::resolve_auto_options`, called at the start of `InnModeller.init_gfn`, fills the options left unset on the command line (`--bounded_rows`, `--min_bin_height` and `--block_orders` default to `auto`, `--tied_derivatives` and `--tied_factor` to none) and prints `options left unset, resolved: ...` with the source of each value. On an unconditional run without `--init_from` the values are `inn_modeller.py::UNCONDITIONAL_DEFAULTS`: bounded rows `linear`, floor $10^{-7}$, tied derivatives with $F = 2$, and the order `Z1_ORDER` when the flow has one block and its live rows are exactly 0 to 11, else the alternating orders. On a conditional run they are off: no bounded rows, no per-row floor, free derivatives, the alternating orders. With `--init_from` they are the checkpoint's saved `inn` entry, a key absent there giving no bounded rows, no per-row floor, free derivatives and the alternating orders. `--no-tied_derivatives` turns the tied derivatives off explicitly.

The option settings are not in the state dict. `min_height` and `tied` are plain attributes of each block, set by `InnModeller.init_gfn`; the bounded-row and uniform-base masks (`is_bounded` on each block and on the flow, `unit_base` on the flow) are buffers registered non-persistent; the half-period rows are a plain list on `LatentFlow`. The state dict does carry `mu`, `sd`, `is_wrap`, the per-row `bound` buffer, whose entries are 1.0 on bounded rows, and the MADE mask buffers and the transformer conditioner's `order` buffer, which encode each block's order. `InnModeller.save` writes the run's flags beside the weights as the checkpoint's `inn` entry. The same weights under a different floor or derivative mode are a different density: under tied derivatives a derivative slot is a factor on a harmonic mean, under free derivatives the argument of a softplus.

With `--init_from`, `InnModeller.train` loads the state dict and compares the checkpoint's `inn` entry with the run's flags. A different height floor or floor rows prints `WARNING --init_from: the checkpoint was trained with bin-height floor ...`, and a different derivative mode or factor range prints `WARNING --init_from: the checkpoint's knot derivatives were ...` ending `the derivative slot changes meaning`; the run continues in both cases. A transformer conditioner whose loaded `order` differs from this run's order for that block raises `ValueError` naming `--block_orders`.

## Conditional runs

On a conditional run (a config that gives each row a condition vector, or `--t_factor` above 1), the sampler is `inn_modeller.py::ConditionalLatentFlow`, whose blocks (`inn_modeller.py::_ContextBlock`) read an embedding of the condition through `inn_modeller.py::_ContextMADE` or a transformer conditioner built with `context_dim`; its wrapped rows take the uniform base and every other live row the Gaussian. `InnModeller.init_gfn` refuses `--block_orders`, `--fold_half_rows`, `--bounded_rows` and `--mix_k` there with `NotImplementedError`, so a conditional flow has the alternating orders and no bounded rows. `--min_bin_height` and `--tied_derivatives` apply as on an unconditional run.

`inn_modeller.py::_ContextFlow.context_input` returns what the blocks and the level head read. Without `--atom_tokens` that is the standardised condition vector passed through a residual MLP (`context`), whose output, projected to the transformer width, a transformer conditioner adds to every token (`CausalTransformerConditioner.forward`), and the standardised vector itself for the level head. With `--atom_tokens`, which requires the transformer conditioner, `InnModeller.pack` puts the condition id in column 0 of the packed condition. `inn_modeller.py::AtomEncoder` encodes that id's molecule from a table of atomic numbers and standard-frame coordinates filled from the conditions files (`InnModeller.note_atoms`). It runs an mxtaltools `ScalarGNN` over each atom's atomic number and coordinates on a radius graph within the molecule (`--atom_cutoff`), and gives one token per atom (the node embedding with an embedding of the atom's coordinates, projected to the transformer width) and an attention-pooled vector which, joined by any further columns of the packed condition (the temperature column on a `--t_factor` run, unstandardised), takes the standardised condition vector's place as the input of `context` and of the level head. Every causal layer of the conditioner (`energies/ar_transformer.py::_CausalLayer` built with `cross`) attends from each slot to all of the molecule's atom tokens after its causal self-attention (`energies/ar_transformer.py::_cross_attend`, padding masked); the output projection of that block starts at zero. A slot's parameters depend only on the rows earlier in the order and on the molecule, so the block's Jacobian stays triangular.

With `--rotate_frames`, which requires `--atom_tokens`, `InnModeller.pack` puts a unit quaternion in columns 1 to 4 of the packed condition: the frame the row's molecule is presented in, the identity unless `InnModeller.context_of` is given frames. `_ContextFlow.context_input` then encodes once per (molecule, frame) pair, with the molecule's standard-frame coordinates rotated by the quaternion's rotation R0 (`inn_modeller.py::quat_to_rotmat`). In the likelihood stage `InnModeller.step_loss` draws one frame per group of `--rows_per_molecule` rows (`inn_modeller.py::random_frames`, uniform on SO(3)) and re-expresses the batch's stored rows for it with `inn_modeller.py::rotate_latent`, before the noise. The crystal builder applies the orientation R of rows 9 to 11 to the molecule recentred on its heavy-atom centroid, so `rotate_latent` replaces R by R R0ᵀ and leaves every other row as it is. Every other caller of `context_of` and `pack` (evaluation, sampling, the energy stage) passes no frames and reads the standard frame. The map from x to its re-expressed rows is not volume-preserving in the chart's coordinates: its log-determinant is log J(x) − log J(x′), with J ∝ sin²(r/2) sin θ the Haar density in the orientation rows' polar angle θ and rotation angle r.

`ConditionalLatentFlow.sample` inverts a transformer block through `invert_block_cached` with the block's context: `CausalTransformerConditioner.decode` adds the context vector's projection to each slot's token, as `forward` does, and projects the atom tokens to keys and values once per layer for the whole decode. Inside `ConditionalLatentFlow.shared_context`, which `InnModeller.train` opens around each update's loss, `context_input` returns its first result for a repeat call on the same tensor with gradients enabled; calls without gradients (the draws') are not kept.

## Could be tooling

- `--init_from` compares the height floor, the derivative mode and a transformer block's order, and takes all three density options from the checkpoint when they are left unset. It does not compare an explicit `--bounded_rows`, whose mask is not in the state dict while the `bound` buffer it sets is and loads from the checkpoint; `--fold_half_rows`; or a MADE block's order, which lives in its mask buffers and loads from the checkpoint without a comparison with `--block_orders`.
- No test exercises `LatentFlow` as a whole: that its `log_prob` normalises, that a bounded row has zero density outside $[-1,1]$, or that `per_dim_log_q` sums to `log_prob`, which is checked only inside `--dump_draws`. `tests/models/test_rq_spline_tied.py` covers the spline alone.
- The `_MADE` comment and the `_knot_derivatives` docstring describe the zero-initialised free spline as exactly the identity with slope 1; the code computes knot derivatives $1 + d_{\min}$ there. The comment beside the floor in `InnModeller.init_gfn` states a minimum mass per bin for every uniform-base row; the derivation above gives it for the block whose output is the base point.
- The in-bin test checks bins $1, \dots, K-2$ only, although the bound derived above also covers the end bins of wrapped and bounded rows.
