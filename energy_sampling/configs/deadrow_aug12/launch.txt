STEP 1 -- conformer regression: ALREADY COVERED BY STEP 0, do not gate on a run
-----------------------------------------------------------------------------
Adding the dead-row kwargs to GFN.get_periodic_dimensions broke this outright --
TorsionGFN overrides that method, so construction raised TypeError before step 0
for every conformer config. Fixed by delegating to _finalize_dim_partition.

That regression is covered by
    test_dead_latent_rows.py::test_subclass_layout_override_still_works
which constructs TorsionGFN at three widths, checks the layout matches the old
hand-written override exactly, rolls a trajectory, and asserts fwd/replay
agreement. It runs in step 0 and needs no config, no dataset and no GPU.

DO NOT gate this battery on `train_conformer.py --config ...`. The conformer
pipeline is under active development, so that entrypoint may fail for reasons
having nothing to do with dead rows -- and someone reading a failure there would
reasonably but wrongly conclude this change broke conformers again. The unit test
is the honest check because it isolates exactly the surface this change touched.

If you do want the end-to-end run anyway (optional, ~2 min, conformer_dev.yaml is
USER-OWNED and unmodified):
    & $PY train_conformer.py --config configs\conformer_dev.yaml 2>&1 | tee configs\deadrow_aug12\e_conformer.log
Reaching step 1 is the whole test; kill it once it is training. Interpret any
failure against the conformer pipeline's own state FIRST, not against D33.

STEP 6 -- the negative test (manual, ~1 min, needs STEP 4 done)
-----------------------------------------------------------------------------
Copy b_sg14_on.yaml, point checkpoint_name at the checkpoint b_sg14_on wrote, and
set model.hold_dead_latent_rows: false. Launching it MUST fail fast with

    ValueError: dead_latent_rows mismatch: this run resolves () ... checkpoint
    was built with (3, 5) ...

That is _assert_dead_rows_match doing its job. Without it, the run would rebuild
from the checkpoint's gfn_config with the rows LIVE while the startup probe
printed reassurance, and log Z would revert to the old scale silently. This is
the single most dangerous failure the change could have, so confirm the guard
fires rather than trusting it.
